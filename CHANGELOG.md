# Changelog

## 1.0.1

New name: **Yeet Bar** is now **Stash Bar**, with a new logo. Nothing else changed, and settings are kept
(the hidden mod ID is still `TopLeftCollapse`).

## 1.0.0 (published 2026-11-18)

First release as **Yeet Bar**: one arrow button that slides the top-left mod buttons in and out.
Optional top-right arrow, Alt + C shortcut and a slide speed option (0.25, 0.5 or 1 second).
